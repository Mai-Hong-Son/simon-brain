process. A product's open work goes to that product's `HANDOFF.md`, never here.

This is not wiki content and is exempt from the AGENTS.md §1 quality gate ("still true and still
useful one month from now?"), because every line is meant to stop being true. Written by `/wrap-up` (Step 3); read by `/wiki-lint`, whose script lists lines older than
14 days.

One line per item. Delete the line when it closes — git keeps the history.
